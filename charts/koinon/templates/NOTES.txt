{{- $pricesMode := include "koinon.pricesRefreshMode" . }}

{{- if eq $pricesMode "off" }}

Model prices: prices.refresh is off (enabled=false), so koinon-api makes no request to any price source and
prices change only with an upgrade. Fetch and review newer ones with
`kubectl -n {{ .Release.Namespace }} exec deploy/koinon-api -- koinon-api prices fetch`, or unset
prices.refresh.enabled (auto) to let small changes apply by themselves.
{{- else }}

Model prices: prices.refresh is {{ $pricesMode }}{{ if eq $pricesMode "auto" }} (koinon-api fetches OpenRouter's public
price list only while an org has an openrouter provider){{ else }} (koinon-api fetches OpenRouter's public price list){{ end }},
and small, stable price changes apply by themselves. The first day brings no OpenRouter estimate: a
fetched price counts only after two fetches 24 hours apart. A model Koinon has no price for at all waits
for a person as a proposal (`koinon-api prices proposals list`); koinon-api logs how many models are
unpriced (metric koinon_price_unpriced_models).
Set prices.refresh.enabled=false to make no request at all.
{{- end }}

{{- if .Values.openshell.insecure }}

WARNING: openshell.insecure=true. Koinon dials the OpenShell gateway without TLS, so sandbox create,
exec and policy calls cross the cluster in clear text unless a service mesh provides mTLS. Set
openshell.clientTLSSecret instead.
{{- end }}

Secret store: provider API keys and connection secrets are encrypted in Postgres with the key-encryption
keys in Secret {{ include "koinon.kekSecretName" . }}{{ if not .Values.secrets.kek.existingSecret }}, which koinon-api creates on its first start{{ end }}. Back it up once it exists; without it they cannot be read:

  kubectl -n {{ .Release.Namespace }} get secret {{ include "koinon.kekSecretName" . }} -o yaml > koinon-kek-backup.yaml

Rotation and the compromise procedure: https://koinon.stateracloud.com/docs/operate/secret-keys/.

Models: add a provider and its models in the UI, with the admin API, or declare them with a labelled
Secret (koinon.dev/secret-type: model-provider); see https://koinon.stateracloud.com/docs/operate/models/.
