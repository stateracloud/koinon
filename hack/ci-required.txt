# The required status checks of the `main` ruleset, by the check's display name (the `name:` of the
# job in .github/workflows/*.yml). This file is the source of truth: the ruleset mirrors it, and
# hack/ci-required-test.sh (CI job `scripts`) fails when a ci.yml job is neither listed here nor
# advisory, or when a name here has no job. `hack/ci-required-test.sh --ruleset` diffs this list
# against the live ruleset.
#
# A required job must report a conclusion on every pull request, every push to main and every merge_group build (the merge queue, ADR 0094). A job-level
# `if:` that skips it counts as passing, which is intended for "this change does not touch my files"
# (and for pull-request-only steps such as the dependency age ones inside `quick checks`: rulesets only check pull request heads).
# Only a workflow-level `paths:` filter leaves a check absent and blocks the merge.
# Every required name must report on `merge_group`: hack/ci-merge-group-test.sh checks the
# trigger, the job's `if:` and its `needs:` chain. `e2e-lab` is information only and never required
# (hack/ci-required-test.sh, also with --ruleset).
#
# Required checks that other workflows produce:
