## Incident: the provider masked prompts

The OpenRouter account had PII masking on. The model received "Agent Sandbox, Daytona, namespace:
argocd" as "Agent [PERSON_NAME], [ADDRESS], namespace: [PERSON_NAME]". A direct request to OpenRouter
with no provider options gave the same result, so the masking came from the account setting, not from
Koinon or the routing guard. Koinon stored the original text.

Effects: the research briefs lost names, FinOps reported "redacted" currency codes and timestamps, and
LCM's first PR replaced `namespace: argocd` with the placeholder. The LCM agent noticed the broken
line itself and wrote "please don't merge it as it stands". All results before 08:43 are tainted. The
FinOps and LCM results below are from the re-run.

Lesson for operators: before a real-model test, send one echo request through the provider key and
check the output is unchanged. A provider check in Koinon could do this (to file).

## Findings

Fixed in rc.6, before v0.1.0:

- [#186](https://github.com/stateracloud/koinon/issues/186): researcher notes outside the workspace end the run. The fix covers both the notes path and the refusal: a refused permission becomes a recoverable tool error.
- [#187](https://github.com/stateracloud/koinon/issues/187): agents get each granted repository's clone URL.
- [#188](https://github.com/stateracloud/koinon/issues/188): a budget stop is recorded as a budget stop. agentd maps 401/429 to the budget reason, and the reconciler cancels runs before revoking the key.
- [#189](https://github.com/stateracloud/koinon/issues/189): `Ask:` takes an email or a user ID.
- [#148](https://github.com/stateracloud/koinon/issues/148): research cost (context compaction and a cost cap).
- [#141](https://github.com/stateracloud/koinon/issues/141): the watch stream missed a run's end.
- Overshoot past the agent daily limit.
- FinOps template: use every allowed cost source.
- RT1 fixture: raise mcp-searxng's per-IP limit.

Noted, not blocking:

- The ledger was about 4% higher than OpenRouter by the end of the day.
- The home-lab values need `api.durable.enabled: true` for schedules.
- There is no run-now RPC for a trigger, so a schedule can only be tested by moving its cron.

### Escape suite

The first run against the home-lab OpenShell: 18 passed, 2 failed, 31 skipped. Both failures are a
test-design problem: `.invalid` hosts fail DNS inside the sandbox before the proxy decides, so
neither case observes a policy decision ([#244](https://github.com/stateracloud/koinon/issues/244)).
Push denial is not shown on the home lab yet. The rc.8 window re-runs it.

### What worked

- **The sandbox observer** bound its role in the new workspace namespace by itself. The fence held
  live: cluster-admin was refused the observer binding.
- **Run now, the per-agent model and the notify target** all worked. Questions went to the org's admins.
- **The full LCM flow on Luna:** a question with evidence, an approval scoped to one PR, a clean PR.
- **Prompt caching:** charged at 16–48% of the uncached price.
- **Budgets:** every agent stayed far below its limit, and nothing logged "agent budget not computed".

### Findings: fixed in rc.8

- [#245](https://github.com/stateracloud/koinon/issues/245) **(critical):** from 12:58 the standalone
  gateway refused every new config. A USD limit net of spend had more than 9 decimals
  (`4.9827242408`), and agentgateway rejects the whole file for that. Keys, revocations, models and
  limits froze at the 12:56 state, and the reason appeared only in the gateway log.
- [#240](https://github.com/stateracloud/koinon/issues/240): OpenCode turns on adaptive thinking for
  every Claude 5.1+ model ID. Direct Anthropic failed every request, because the gateway strips the
  beta header the field needs. **Decision:** thinking is on by default, with a per-agent opt-out, and
  Koinon decides, not the harness.
- [#243](https://github.com/stateracloud/koinon/issues/243): the run token cap counted cached input,
  so research was cancelled after about 20 requests that cost $0.03. **Decision:** a request cap and a
  per-run USD cap plus the wall clock replace it. Tokens are reported, not enforced.
- [#241](https://github.com/stateracloud/koinon/issues/241): requests the provider refused were
  charged their input estimate.
- [#246](https://github.com/stateracloud/koinon/issues/246): a provider 403 was reported as a fatal
  gateway-key failure.
- [#242](https://github.com/stateracloud/koinon/issues/242): remove the OpenRouter `anthropic/*`
  format pins, since the live check passed.
- [#247](https://github.com/stateracloud/koinon/issues/247): OpenCode's built-in `webfetch` is
  offered although sandbox egress is closed, and models used it instead of the web-search tools.
- [#244](https://github.com/stateracloud/koinon/issues/244): the escape tests' host names, above.
- The RT1 fixture: SearXNG engines without DuckDuckGo, and more CPU and longer probe timeouts for its MCP server.

  `koinon-pull` ExternalSecret. Koinon's own pods were unaffected.
- SearXNG engines and resources, as above.
